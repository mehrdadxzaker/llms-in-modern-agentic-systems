# Repository website source

This is the editable repository-facing project hub. It shares its typography, color tokens, and responsive behavior with `../project-page/` through `../site-shared/theme.css`.

The production GitHub Pages build is assembled in `../docs/` and deployed by `../.github/workflows/pages.yml`. Keep this source view synchronized with `../docs/index.html` whenever paper metadata, reference counts, or navigation links change.
